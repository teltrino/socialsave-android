# Tellawy downloader 0.3.0

1. Transfer Tellawy-downloader-0.3.0.apk to your phone and install it over the existing version. Do not uninstall first.
2. Paste or share a link. YouTube title/creator use a lightweight preview and repeated links use cached details. You can start downloading before the preview finishes.
3. Choose MP4 resolution or MP3 bitrate and tap Download.
4. Files are saved to Downloads/Tellawy downloader. Old files remain in Downloads/Sahab.
5. If a download fails, open View error details, then Copy details. Persistent DNS errors need a working connection to the media server; the app cannot fix the phone's DNS/network itself.

The manual update button is removed. The app checks official engine updates in the background when opened, with a five-minute cooldown for rapid reopens. Checks/downloads do not block previews or downloads. A verified update waits for an active extraction to finish before installation. If checking fails, the installed engine stays available.

The engine is the part that understands source websites and finds downloadable media. Updating it keeps support working as sites change. About shows the installed engine version and the last update-check status.

Try the previously failing video as MP4 at 720p, then try MP3 again. Android downloading/remuxing and saving still require your device trial. Allow notifications and OPPO background activity if downloads stop when the screen locks.

Make the accompanying source archive available when sharing the APK. Never share .tools or signing keys.
